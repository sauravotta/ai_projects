# AI Projects

A collection of small AI projects. Each lives in its own folder with its own README and dependencies.

| Project | Description |
|---------|-------------|
| [starter-ai-agent](./starter-ai-agent) | Minimal CLI agent with tool calling via OpenRouter |
| [ai-agent-swarm](./ai-agent-swarm) | 4-agent swarm (Coordinator, Researcher, Writer, Critic) using tool-call handoffs |
| [ai-agent-fleet](./ai-agent-fleet) | Java fleet demo: autoscaling, heartbeats, retries, dead-lettering |
| [ai-agent-team](./ai-agent-team) | .NET team demo: a lead and teammates coordinating through a shared task list |
| [ai-observability](./ai-observability) | .NET LLM observability demo: OpenTelemetry traces and scores in a Langfuse dashboard |
